# 男子新体操国際化プロジェクトのメインサイト

## Init

```bash
npm install
```

## Developing

```bash
npm run dev

# or start the server and open the app in a new browser tab
npm run dev -- --open
```

## Building

```bash
npm run build
```

> [!NOTE]
> Amplifyのビルドが失敗してしまうためNodeのバージョンは16系を使用しています。


## Lint
### Check
```bash
npm run lint
```

### Fix
```bash
npm run lint:fix
```

### format
```bash
npm run format
```
